# Blind King: Project Brief

The owner's brief, verbatim, given at project setup on 2026-11-06.

> The title is "Blind King".
>
> Goal: a carplay compatible app for iOS to solve chess puzzles blindfold.
> It needs to read the board, understand spoken moves by the user and let the user know if they're correct or not.
>
> There will be different modes available:
> - single position. Find the correct move.
> - Continuation puzzles: multiple moves. If there are different variations each variation will need to be answered independently;
> - from the start: app reads moves from the starting position, until it reaches a point where the narration pauses and asks the user what move should player White or Black play next.
> - Hybrid: starting from a position in the middle of the game, app reads a few moves until it stops at the point where the user must guess.
>
> This is all blindfold, no animations required. But UI needs buttons to skip 1 move back, 1 move forward, rewind to start, go to end, etc. as user may need to repeat the same narration multiple times to keep up with what's being player.
>
> different levels of difficulty, and different themes.
>
> Puzzles come from lichess.
